📖 功能介绍

DrugCLIP 是一个基于深度学习的虚拟药物筛选平台，用于预测分子与蛋白质的结合亲和力。

🔬 输入说明

  • 分子 SMILES：SMILES（Simplified Molecular Input Line Entry System）是分子的字符串表示法。例如：CC(C)Cc1ccc(cc1)C(C)C(=O)O
  • 蛋白质口袋 ID：PDB 数据库中蛋白质结合位点的标识符。例如：1a30（HIV蛋白酶）

📊 输出说明

  • 结合分数：负值表示更强的结合亲和力。范围通常为 -10 到 10。
  • 结合概率：0-1 之间，表示分子与蛋白质结合的概率。
  • 置信度：模型对预测结果的置信程度。

💡 使用技巧

  • 对于批量预测，使用 .smi 文件格式可以一次筛选数千个分子。
  • 预测分数越低（更负），结合亲和力越强。
  • 可以下载结果为 CSV 或 JSON 格式进行后续分析。

🔗 数据来源

  • 蛋白质结构：PDB 数据库
  • 模型：DrugCLIP（NeurIPS 2023）
  • 训练数据：PDBBind + HomoAug

⚠️ 注意事项

  • 预测结果仅供参考，不能完全替代实验验证。
  • 确保输入的 SMILES 字符串格式正确。
  • 大规模批量预测可能需要较长时间，请耐心等待。
